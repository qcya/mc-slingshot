# MC方块弹射 | MC Block Launch

A Minecraft-style flat-map siege game: launch blocks and stones from the left to destroy villager houses and monster ruins on the right.  
一个 MC 方块画风的平面攻城游戏：在左侧发射方块和石块，击毁右侧的村民房屋与怪物遗迹。

**Alpha 0.3 · 方块场景与投石车修复版**

## 开始游戏

下载本仓库并解压，打开 `index.html`；如果浏览器限制本地读取贴图和音效，在 Windows 上双击 `START_GAME.bat` 启动本地 HTTP 服务。使用 Edge 或 Chrome。

拖动投石车上方的方块，向左后方拉动并松开来发射。`1`～`4` 切换弹药，`R` 重开，`N` 切换下一关，空格暂停。游戏已有五个场景：草地小屋、石头哨塔、双子木楼、掠夺者前哨站、像素要塞。

首版四种弹药：**圆石方块**（方形实体撞击）、**TNT 方块**（圆形区域破坏）、**末影珍珠**（有限距离穿透薄墙）、**黑洞**（黏附并逐渐吸走像素）。

## 这次修了什么

- **场景从完整原版 MC 方块起步**：地图内全部可破坏建筑、地面、树木均使用严格对齐的完整 16 × 16 原版纹理方块。世界单位中的一个 Minecraft 方块占 16 × 16 个可独立破坏的材质格（每个显示为 5 × 5 画面像素），即默认呈现 80 × 80 画面像素的方块。木屋屋顶、柱子、平台都只能由整块方块组成；爆炸后才产生缺口。
- **不再生成正弦波坡度和光滑山丘**：地面水平、完全方块化；云也为像素矩形。
- **圆石与 TNT 使用方形 AABB 与真实剩余地形像素碰撞**：撞击时逐步子步前进，按实际接触面反弹或停止。低速落地会停稳，不会无限自转或钻地。
- **有车轮、车架、杠杆、配重、弹药兜的投石车**：拖拽控制力度和角度，松手后投石臂摆动；修复弹药贴图位置未加相对偏移，导致之前弹药没有画在发射器上的 bug。
- **继续保留逐像素挖坑与碎片淡出**，建筑连通性改变后生成掉落残骸。`vendor/matter.min.js` 为 Matter.js，负责掉落大块残骸的刚体模拟。
- **声音**：草、泥土、石头、木头、玻璃等破碎/撞击音效；守卫死亡会触发玻璃破碎音效。

## 技术边界

这是可玩物理原型，而非精确有限元建筑模拟。像素破坏与发射物的碰撞由自定义二维网格承担；脱离支撑的大型残骸使用 Matter.js 刚体，形状暂时采用包围盒近似。复杂建筑多体碰撞仍需要迭代。**没有加入创意工坊、图像转关卡或 AI 地图生成功能**。

该版本的本地自动浏览器测试已覆盖五关初始化、拖拽发射、圆石停稳、TNT 像素破坏、末影珍珠、黑洞和粒子效果（脚本错误为零）。这次离线测试使用的是物理降级路径（测试环境无法载入网络或外部引擎）；完整下载版中已内置 Matter.js。请继续在本机测试原生引擎模式下的大型残骸。

## 文件

- `index.html`, `style.css`：主界面
- `game.js`：关卡网格、逐像素破坏、方形碰撞、投石车、物理与声音规则
- `assets/textures/`：16×16 方块纹理与物品贴图
- `assets/sfx/`：游戏内音效
- `vendor/matter.min.js`：本地封装的 Matter.js 引擎
- `START_GAME.bat`：Windows 本地启动辅助

相关素材来源与许可见 `LICENSES.md`，开发用两个原仓库均不修改。
