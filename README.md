# 拉满的石 / Stone at Full Draw

弹弓发射 Minecraft 方块与物品，逐像素破坏固定建筑，清除怪物。**Alpha 0.13.4：Toy 包解压后可直接双击试玩，修正本地音效读取失败；保留图片跨域修复、完整冰封、玩法介绍、依次解锁和后腿修正。**

## 开始游玩

在线试玩：[拉满的石](https://qcya.fun:8443/mc-block-launch/)。电脑使用鼠标，安卓手机建议横屏。开局设置昵称，不需要密码；关卡进度保存在当前浏览器，排行榜由服务器共享保存。项目仓库：[qcya/stone-at-full-draw](https://github.com/qcya/stone-at-full-draw)。改名保留已有试玩地址、存档键和服务数据目录。

家中同一局域网使用 [192.168.1.4:8770](http://192.168.1.4:8770/)，避免 NAT 回环；内外网使用同一服务端排行榜。浏览器身份和本机关卡进度按访问地址分别保存。

Windows 玩家可下载[0.11.0 历史试玩包](https://github.com/qcya/stone-at-full-draw/releases/tag/v0.11.0)，完整解压后双击 START_GAME.bat，保留启动窗口。包内自带已校验的 Node.js，不用安装开发工具。不要只提取启动器，也不要直接打开 HTML。离线包使用本机排行榜；与朋友比较成绩请使用上面的在线地址。本轮不生成新的下载包。

源码包含素材和 Matter.js，需要 Node.js 20+ 或 Python 3。双击 START_GAME.bat，或运行 npm start。端口占用自动换端口；复制启动窗口显示的实际地址。Python 静态模式仍可离线玩，排行榜需要 Node 服务。离线通关成绩暂存本机，恢复同一站点的服务后重试上传。

## 操作与闯关

- 拖住弹药调整方向和力度，松开发射；可向后、轻抛。只点一下而没有拉动不会消耗弹药。右键取消；手机拉弓时用另一根手指轻点任意位置取消。
- 首页使用实时村庄木屋与像素木叉弹弓场景，点击任意位置（或 Enter／空格）进入选关；右上角可打开更新公告，左上角可打开玩法介绍，暂停后的设置里也能查看。首次游玩先设置昵称。选择主世界、下界或末地，各十关、每页五关，横竖屏均竖排，保留个人最快时间与点按道具提示。
- 原版九格物品栏，数字键 1–9／滚轮切换；依次是圆石、TNT、末影珍珠、烈焰弹、雪球、风弹、喷溅型水瓶、黏液球、铁砧。所有已解锁弹药都显示数量（含1）；本关未配或已用完时保留暗图标与0。未解锁格为空。触屏保持可见，电脑闲置后自动隐藏。
- ESC / 手机左上角“暂停菜单”暂停；依次提供继续游戏、重新开始、设置、选择关卡、返回主菜单。游戏音效随暂停停住，继续后从原位置播放；重开或换关会清掉旧音效。设置可开关音效、调节音效音量并保存，也可独立开关音乐。R 重开当前关，切到其他应用自动暂停。
- 选关“全屏”优先调用 Toy App 的横屏沉浸接口，再尝试浏览器全屏与方向锁定；成功后按钮显示“取消全屏”，点击退出并释放方向锁，不支持时显示提示。真实手机仍需验收。
- 通关页显示本次用时和个人最快；选关卡片右侧显示个人最快，只有点击“道具”才展开本关弹药短清单，再点一次或点空白处关闭。总榜保持十关全通后上榜，只展示各关最快用时之和。
- 主世界第一、二、三关分别解锁 TNT、末影珍珠、烈焰弹。主世界十关全通后解锁下界，下界十关全通后解锁末地；每个世界内逐关解锁。下界第1、4、7关加入雪球、风弹、水瓶，末地第1、4关加入黏液球、铁砧。解锁依据当前地图的有效通关记录，旧地图的解锁标记不能打开未通关的新地图。
- 清场后等待死亡粒子消散再显示通关；所有弹药和正在进行的攻击结束后才判失败。
- 默认低音量循环 C418《Sweden》，第一次点击后开始播放；暂停菜单可独立开关音乐，偏好自动保存，切后台自动暂停音乐。

## 武器与敌人

| 弹药 | 材料效果 | 生物效果 |
|---|---|---|
| 圆石 | 方形刚体，按冲量破坏接触像素；玻璃轻碰即碎 | 普通怪直接击杀，监守者需三枚不同圆石 |
| TNT | 四秒引信；飞行接触仅碎玻璃；爆炸挖去实体方块像素 | 无接触伤害；监守者需两次范围内爆炸 |
| 末影珍珠 | 无损穿过一面厚度不超过两完整方块（96px）的墙，出口必须安全 | 飞行命中普通怪直接击杀；监守者需四枚；落稳后无接触伤害 |
| 烈焰弹 | 逐像素点燃命中格及上下左右四邻格中的木材，最多五格 | 每发三次持续伤害；普通怪三次烧死，监守者六次 |
| 雪球 | 不破坏方块 | 命中后停止地面巡逻四秒，保留重力和外力击退 |
| 风弹 | 不挖去地形，推开附近物品 | 范围击退，可把敌人推入熔岩 |
| 喷溅型水瓶 | 灭火，局部熔岩冷却成黑曜石 | 熄灭生物身上的火焰 |
| 黏液球 | 高弹性反弹，不挖去方块 | 可反弹命中；同一枚对同一怪物只伤一次 |
| 铁砧 | 沉重重击，弹道下坠更快 | 对高耐久目标造成重击伤害 |

烈焰弹可烧实体层的原木、木板、门、台阶和梯子；不烧土、石头、玻璃，也不独立点燃背景墙和背景家具。实体像素烧毁时，同位置背景一并消失。只点燃命中格和上下左右各一格中的可燃实体，不向更远处蔓延，不在空气中生成木材火焰。使用原版火焰动画与音效。

圆石、珍珠、黏液球和铁砧仅在自身速度达到有效撞击门槛时伤人；静止或慢滚时不因怪物主动碰触而扣血，被炸飞或落下后可以重新形成有效撞击，同一枚对同一只怪物仍只计一次。珍珠发射五秒后开始淡出，成功穿墙后重新计时五秒；飞行中命中怪物仍可继续飞行。熔岩会点燃圆石，撞击命中后额外造成三段共50点灼烧，两枚燃烧圆石可击败监守者，水瓶可以熄灭石头上的火。

命中不可燃墙面或天花板不会起火。落到地面顶面时，在落点及左右各一格留下最多三格、持续2.8秒的横排地火；每格都检查下方实体支撑，不生成上下悬空火焰。支撑破坏后，对应地火消失。经过地火的怪物同样会受到三段燃烧伤害，矿物本身保持完整。

**背景包括暗色墙面与淡色家具，没有实体，不参与碰撞；前景像素破坏后，同位置背景一起消失，TNT 还能直接炸毁露出的背景。** 工作台、熔炉、书架为背景装饰，不挡弹药或怪物，不独立点燃或蔓延燃烧；玻璃、门保留实体和正常亮度。建筑使用整格方块、玻璃及半格楼梯形状，楼梯下的实心衔接让屋顶连成一体；画面和碰撞网格一致，失去支撑的建筑仍固定。第一关木屋由掠夺者驻守。爆炸能推动场上弹药，TNT 各自保留引信。弹药、敌人使用本地 Matter.js 0.20.0，无降级物理模式。

监守者（用户所称坚守者）在第九、十关出现，使用独立大体型碰撞、原版皮肤和立体四肢动画。同一颗圆石反复接触只算一次；爆炸后的落地伤害不会额外扣除其耐久，跌出场景仍算击败。普通怪物会行走、停步观望和抬手，受伤泛红、倒地、白色粒子消散。

下界使用下界砖、黑石、玄武岩、菌木等原版材质，熔岩从高处向下流动，破坏地形后会改变流路。僵尸猪灵免疫火焰和熔岩；疣猪兽与监守者同级耐久，三枚圆石或两次有效 TNT 爆炸可击败。

末地使用末地石、紫珀和黑曜石。潜影贝随机开合，闭壳要三枚圆石，开壳时命中一枚即可。末影人第一次有效攻击后瞬移，第二次新的攻击击败；落点在画面内，检查地面、实体、熔岩与其他生物，不会把同一枚弹丸算作两次攻击。

## 自建网站的昵称与排行榜

昵称为 1—16 个汉字、字母或数字，可含空格、下划线、短横线。浏览器保存匿名身份令牌，服务器只保存令牌哈希；改名不会丢失成绩。清除站点数据会失去身份。

新建和改名都由服务器检查昵称是否已被占用，忽略大小写、全角差异及多余空格；冲突显示“用户名已占用”。离线昵称联网后若冲突，需要重新命名。本轮三个新榜不注入旧版演示行或历史成绩。

所有玩家都能查看三个世界各自的排行榜，最多显示最快的 **100 人**。闯关保存各关个人最快用时，**每个世界十关全通后才上传该世界的成绩**。总排名按十关个人最快用时之和升序；重玩更快即可刷新，暂停不计时。新地图重开赛季，旧成绩归档备份，身份保留，当前地图的有效通关时间决定解锁进度。服务器拒绝旧版本回灌成绩。此榜供朋友试玩，成绩由客户端上报，不具备比赛级防作弊。

## 开发与服务部署

安装开发依赖后执行：

```powershell
npm ci
npm run check
```

测试使用完整 Matter.js 和 Edge / CI Chromium。实际结果与截图见[测试记录](docs/TEST_RESULTS.md)，素材见[LICENSES](LICENSES.md)和[战斗素材](docs/combat-assets.md)，修改见[CHANGELOG](CHANGELOG.md)。两个素材来源仓库保持只读。

Toy 构建运行 `npm run build:toy`，输出普通脚本的独立前端目录；使用 B 站账号、官方云存档和三张原生计时榜，排名精度 0.01 秒，不依赖家庭服务器。与自建网站榜单独立。**现有作品 ID `45155222811648`，地址 `Stone_at_Full_Draw`，更新包交给作者在[上传入口](https://www.bilibili.com/toy/publish)手动更新。** 主世界、下界、末地继续使用榜2、3、4，榜5保留。0.13.1 已发布且旧榜1已清空，本轮不更改排行榜、云存档键或成绩赛季；平台历史详见 [Toy 说明](docs/TOY.md)。

Node 服务默认绑定 127.0.0.1:8766，可设置 HOST、PORT、MC_DATA_DIR。排行榜目录必须在游戏目录之外，每个数据目录只能运行一个进程，重启保留成绩。公网通过反向代理部署，见[部署说明](docs/DEPLOYMENT.md)。不要把连接凭据、成绩文件或开发依赖放进公开目录。

当前边界：三世界共三十关；创意工坊暂未实现。人物外观立体，物理仍为二维，不会沿梯子寻路。真实手机性能与公网连通需设备试玩反馈。旧版 iOS 暂缓。瞄准五点显示前半秒自由飞行趋势，不预测碰撞反弹。
