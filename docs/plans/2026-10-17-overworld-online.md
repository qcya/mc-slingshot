# 主世界十关与在线试玩

本阶段只发布主世界 1—10 关。保留原版纹理、逐像素破坏和固定建筑；不制作地狱、末地、旧版 iOS 兼容层。

## 实现顺序与约定

1. 战斗：第四种弹药 ID `fire`，第三关后解锁。木材火焰按方块坐标传播，离起点最多三格，限时消耗前景及后墙的木质像素。坚守者使用独立比例、贴图和动作；三发圆石或两次 TNT 爆炸击败，同一次攻击不能重复计数。
2. 关卡：十种手工场景，逐步增加地形、掩体和敌人组合，第九、十关含坚守者。保留旧存档并用实际物理模拟验证可通关，弹药更紧凑。
3. 操作与画面：修正弹弓绑带位置；手机提供暂停、取消、物品栏入口和横屏提示，保留桌面键鼠。适应安全区域和浏览器视口变化。
4. 在线：开局设置昵称，服务端持久保存每关最佳成绩，按通关数、耗弹数、用时排序。昵称无需密码；这是朋友试玩排行榜，不宣称防作弊。菜单使用现有 MC 按钮与泥土背景。
5. 检验：单元测试、完整 Matter.js 浏览器流程、十关求解、Android 触控模拟、实际截图和声音加载检查；修复后提交 GitHub。
6. 部署：读取用户提供的服务器连接配置，在独立目录和服务运行；沿用服务器已有 HTTPS 入口增加游戏路径，保留原服务。数据独立于发布目录，验证公开地址后交付链接。

## 文件边界

- 战斗任务：world/mobs/fire、专用测试和新素材。
- 关卡任务：levels/campaign、关卡测试和通关脚本。
- 在线任务：serve/leaderboard/online、HTTP 测试。
- 主任务：app/renderer/config/assets、HTML/CSS、触屏测试、部署及最终整合。
