# 三世界扩展设计

用户要求重建主世界十关建筑，保留主要解题逻辑和怪物；加入下界、末地各十关、流动岩浆、新怪物、五种原版物品，并修整弹弓。沿用用户“拿得准直接做”的授权，在现有项目中实现并提交 GitHub、部署家用试玩。后续用户明确要求删除旧 Toy、重新建立三榜，并增加开始菜单更新公告；先完成可审看的新版，不提前删除入口。不恢复视频工作。

## 世界与成绩

三个世界使用固定 ID：overworld、nether、end，各自关卡编号 0–9，分别绑定 Toy board 1、2、3。每个世界首次开放第一关，世界内按顺序解锁。保留经典五关一页、单行编号/名称/最快时间/道具按钮。

以用户后续指示为准：三张榜全部从新地图重新计时，不带入旧成绩或示例行。身份和主世界已解锁关卡保留；原成绩只做私有归档备份。Toy 原生榜只增不减且无清榜接口，因此这次必须新建作品，不能把新包更新到旧 ID 45155222811648 后宣称清榜。每个世界独立记录十关最快时间，全通各自十关才提交各自总榜；身份共享，缓存和待提交队列按世界隔离。

本机时间使用 best-times.v2、队列 pending.v3，新世界追加 .nether/.end。Toy 使用 mcslingshot_save_v2 与 mcslingshot_dimensions_v2，旧 v1 仅迁移主世界解锁进度。家用服务数据升级 v4：原分归档后新三榜为空，只迁移一次；旧客户端提交不带赛季标识时拒绝，防止旧地图成绩回灌。所有读分和提交先检查服务器赛季。云读取失败不覆盖云端，写入串行且失败退避。

## 地图和美术

三十关使用实际原版材质，关卡结构各有差异，避免仅换皮复制。同一前景/后景破坏规则沿用：前景消失时对应背景消失；背景墙较暗，家具为较淡的非碰撞装饰；没有背景玻璃；房屋不会因支撑消失自动坍塌。主世界僵尸保留遮阴位置，掠夺者留在建筑与守卫平台。

下界使用下界岩、下界砖、黑石、玄武岩、绯红与诡异木材；末地使用末地石、末地石砖、紫珀与黑曜石。远景、天空、地下填色按世界切换，下界和末地不出现主世界白云和樱花树。

弹弓保留原瞄准位置与力度映射，改成与场景一致的像素木叉。两个固定绑点位于叉头内侧，皮筋连到兜子的两个端点；皮兜随拉伸方向转动且真实包住弹丸。改变外观不改变已有瞄准坐标。

## 怪物与岩浆

- 僵尸猪灵：沿用人形骨架、原版皮肤，常规敌人血量。
- 疣猪兽：四足身体与獠牙，耐久与监守者同级，300 HP；三枚不同圆石或两次有效 TNT 爆炸。
- 潜影贝：随机时段开合，有可读动画。闭壳三枚不同圆石，开壳命中一枚即击杀；同一枚弹丸反复接触不重复计伤。
- 末影人：第一枚有效攻击后瞬移，第二枚新的有效攻击击杀；至少三个不同可用落点，落点在画面内、具有支撑且无实体重叠。使用真实物理环境检查落点，不能钻墙或落入岩浆。
- 岩浆独立于实体网格，受重力向下流；遇到支撑有限横流。前景被打穿后重算流路。触及非免疫怪物造成灼烧；关卡不能不发射便自动清场。模拟有更新频率和单元上限。

## 九格道具

固定顺序：圆石、TNT、末影珍珠、烈焰弹、雪球、风弹、喷溅型水瓶、黏液球、铁砧。下界第 1/4/7 关逐步加入雪球、风弹、水瓶；末地第 1/4 关加入黏液球、铁砧。雪球减速，风弹范围推力，水瓶灭火并冷却局部熔岩，黏液球弹跳，铁砧重击且弹道下坠更快。保持圆石为主，按地形配给，保留九格耗尽图标与 0。主菜单增加可滚动的更新公告，创意工坊留待未来，不纳入本轮。
