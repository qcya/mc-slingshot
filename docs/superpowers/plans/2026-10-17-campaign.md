# 闯关与操作修订实现清单

> **For agentic workers:** 使用 superpowers:executing-plans，在本会话逐项实现与验证。用户已明确授权直接开发和完成后上传 GitHub。

**Goal:** 五关逐步解锁、独立弹药库存、ESC 菜单与正确的发射提示，并落实最新美术反馈。

**Architecture:** campaign.mjs 保存关卡库存和持久进度；app.mjs 管理菜单和游戏状态。物理保持 Matter 与逐像素破坏。scenery/renderer 只处理原版阁楼、远景、云、弹药兜和八点预览。

**Tech Stack:** 原生 ES modules / Canvas / Matter.js / Playwright。

**Spec:** 当前用户反馈：第一关五个圆石；第二关四个圆石一个 TNT；第二关解锁珍珠，此后不新增物品；无顶部按键，ESC 菜单；物品栏自动下滑隐藏；原版楼板梯子代替横梁；自然远景与树、动态云；原版拉弓声；兜面垂直于发射方向；始终八个预览点。

## 约束与核验

- 只保留圆石、TNT、珍珠三种弹药；石材硬于木材；房屋固定，前后景均能破坏。
- 不消耗未选中的弹药；取消不扣弹；数量为零不能发射；重开恢复本关库存。
- 未通关不能跳关；刷新保留进度；损坏存档回到第一关。
- 预览不因墙或树消失，八点落在可见画布内；与真实自由飞行使用相同参数。
- 原版声音可取消和静音，界面隐藏不能使滚轮失效；ESC 不遗留拉弓状态。
