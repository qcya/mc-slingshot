官方 SDK 分数为整数且只增不减，Toy 采用 `10000000 - ceil(总毫秒/10)` 编码，时间越短分数越高，覆盖十关各一小时的允许上限；排名精度 0.01 秒，本机和云存档仍保存原始毫秒。提交前读取自己的已有成绩，旧/相同成绩不重复写；榜单短时缓存、手动刷新、限流退避。原网站继续保留毫秒排名。

本地真实双 Origin 浏览器保留了原自建 API 的跨站回归。最终 Toy 包另外使用真实官方 SDK 原文件与本地父窗口消息宿主，验证原生身份、云读写、原生榜单和零家庭 API 请求；从模拟云恢复身份和断网保留存档也已验证。模拟宿主不能替代真实平台返回结构和真实安卓设备实测。最终 Toy 包不依赖自建 API 的 DNS、HTTPS 或 NAT 回环。
