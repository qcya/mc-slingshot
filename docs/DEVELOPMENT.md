# MC 方块弹射开发记录（2026-10-17）

目标以用户完整任务书为准：五个手工关卡、四种弹药、原版素材、16×16 像素破坏和可信的物理攻城。两个素材仓库仅作只读来源。

## 初始实测

- 基线提交：`6a5719d`。Edge 实际打开，Matter.js 0.20.0 已加载。
- `oak_leaves.png`、`iron_ore.png`、`deepslate.png` 返回 404，代码静默改用随机色块。
- 弹药和怪物自行积分，只有残骸使用 Matter；残骸只有包围盒，且不与静态建筑碰撞。
- 删除残骸像素不更新碰撞形状；固定地板与挖掉的地形不一致。
- 装饰树参与承重；怪物皮肤的头、身体、腿被非等比缩放。
- 基线证据：`evidence/baseline.json`、`evidence/baseline.png`。

## 设计

这是一次架构修复。沿用本地 Matter.js、已有正版风格贴图、Canvas 和可用操作方式。所有可运动的实体交给同一个 Matter 世界。静态地形保留材质像素，碰撞网格由剩余像素合并矩形生成；脱离支撑的连通结构变成复合刚体。残骸继续保存像素，损坏后重新分割与生成碰撞形状，保持姿态和速度。

树木与远景单独绘制，不参与建筑承重。所有关卡从完整方块开始。必需素材加载失败时显示错误，不再伪装加载成功。四种武器分别实现冲量破坏、延迟爆炸、测量墙厚并验证安全出口、定时限量吞噬与引力。

用户已明确要求检查后直接开发，本记录不增加设计审批环节；由当前会话直接实现，最终进行独立代码审查。

1. [x] 启动和素材：资源回归先复现三处 404，补齐后 Edge + Matter 正常模式五关切换通过（1/1）。新增素材、测试依赖和基线证据。

4. [ ] 全量复验：完整 Matter 模式下测试所有关卡与弹药，保留截图、性能数据、已知边界，更新中文 README，提交并推送。

风险重点：薄墙高速穿透、挖洞后隐形碰撞、旋转残骸二次分裂、重复碰撞伤害、关卡重开后的刚体泄漏、最后一发仍在运动时过早结算。

追加验证：承重截面重心越界时将上方结构交给 Matter，通过接触产生转矩；没有预设倒塌动画。新增睡眠弹药失去支撑后唤醒、黑洞全局吞噬预算回归。当前 17 个 Node 测试与 4 个 Edge 浏览器场景均通过。`evidence/` 保存五关前后与四种弹药截图、实际物理模式及性能记录。Playwright 在本机 Windows 上录制 trace 曾发生 EBUSY，因此采用失败截图与 JSON 证据；关闭 trace 后复测通过。
