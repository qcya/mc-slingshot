# 开发记录（2026-10-17）

## 当前设计：Alpha 0.7.1

用户最新要求覆盖初始攻城坍塌方案：房屋与后墙永远固定，仅保留逐像素破坏。移动弹药与敌人使用同一个本地 Matter.js 世界；地形保存材质像素，损坏后重建精确矩形复合碰撞。后墙单独保存像素，没有碰撞。正常游戏不会将建筑转成动态残骸。

- `src/world.mjs`：碰撞、像素损坏、玻璃整片破碎、四种武器、爆炸速度冲量。唤醒附近睡眠弹药，其他 TNT 不改引信。
- `src/pixels.mjs`：16×16 初始完整材料与耐久、损坏、碰撞合并。
- `src/rear.mjs`：固定且独立可破坏的房屋后墙。
- `src/sling.mjs`、`src/aim.mjs`：任意方向、小力度、统一物理预测；装饰树没有碰撞。
- `src/draw-audio.mjs`：用户操作开启 WebAudio，拉伸音随动作变化，取消/暂停/重开均停止。
- `src/behavior.mjs`、`src/mobs.mjs`：巡逻与停步切换，连续肢体、头部及抬手动画；敌人碰撞过滤允许互相穿行。
- `src/renderer.mjs`：透明 PNG 弹弓、独立皮筋/弹药兜；静态背景缓存、右侧单棵樱花树、静态云和原版像素场景。
- `src/app.mjs`：输入、右键取消、九格物品栏与最小界面。

遗留的通用动态残骸辅助函数仍有单元测试，但不会在本版建筑破坏中自动调用。将来如需恢复另一种游戏模式，应明确切换规则。
