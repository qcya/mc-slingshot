# 开发记录 — Alpha 0.9.0

当前用户要求：三种弹药闯关，第一关解锁 TNT、第二关解锁珍珠，后续只组合和增加难度。移除黑洞及顶部工具栏。建筑固定，仅逐像素破坏。

- `src/campaign.mjs`：五关独立库存、进度校验、锁关与通关存档数据。
- `src/app.mjs`：选关/游戏/暂停/奖励状态，用户输入、库存扣除、隐藏物品栏与界面。
- `src/item-icons.mjs`：用原版顶面和侧面纹理组成物品栏方块图标。
- `src/aim.mjs`、`src/sling.mjs`：同一 Matter 参数的八点自由飞行预览、拉伸限制、垂直于发射方向的兜面。
- `src/draw-audio.mjs`：用户手势开启的原版弩加载采样；释放/取消/暂停/重开停止。
- `src/world.mjs`：统一 Matter 物理、逐像素伤害、整片玻璃破碎、TNT 冲量、珍珠测墙厚。
- `src/scenery.mjs`、`src/renderer.mjs`：原版纹理远景、动态方云、前后景明暗、接触阴影。光照随前后景版本更新。
- `src/levels.mjs`、`src/rear.mjs`：手工关卡与固定可破坏后景。阁楼为原版木台阶侧面及梯子，取消额外绘制的横梁。
- `tests/`：正常 Matter 核心测试和实际鼠标浏览器测试；开发辅助可在测试存档中预先开放关卡，正常新玩家仍只能第一关开始。

接手基线为 `6a5719d`，曾有资源 404、混合伪物理、碰撞与像素不一致。0.6 统一物理，0.7 根据反馈取消房屋坍塌，0.7.2 修复端口占用启动。0.8 视觉方案按后续反馈调整后，与 0.9 闯关一起交付。

当前有限弹药回放位于 `evidence/playability-search.json`。可运行 `node scripts/check-playability.mjs` 重新搜索全部关卡，或追加关卡编号仅验证一关。搜索工具不参与游戏，也不会自动替玩家瞄准。
