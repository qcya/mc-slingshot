# 实际测试结果 — Alpha 0.10.0

2026-10-17，Windows / Node.js 24 / Edge / Matter.js 0.20.0。完整物理模式，无降级路径。

## 最终执行

`npm run check`：**49/49 核心测试、16/16 Edge 浏览器场景通过**；浏览器部分约 1.9 分钟。此结论来自本地执行，不代表远端 CI 已执行。

## 本次反馈验证

- 三种弹药均为 28px；圆石/TNT 为方形碰撞，珍珠为半径 14 的圆形碰撞。弹弓截图见 `sling-cobble/tnt/ender.png`。
- TNT 慢速直接接触怪物不扣血，同一怪物被爆炸击杀；接触木材、石头不破坏，接触玻璃即碎；四秒引信与两颗 TNT 相互炸飞继续通过。
- 珍珠针对木门上下半、玻璃、石砖，分别测试薄墙/厚墙、可穿墙/已用过穿墙：实际 Matter 碰撞后，前景材料和每像素耐久均保持原值，后景也未破坏。薄墙安全出口和厚墙阻挡测试通过。
- 真实鼠标圆石命中第一关怪物后，依次捕获红闪、倒地、白色粒子；尸体碰撞只移除一次，白色粒子结束后才出现胜利菜单。见 `mob-hurt.png`、`mob-fallen.png`、`mob-poof.png`、`mob-death.json`。
- 最后 TNT 爆炸后残血怪物延迟摔死：真实 Matter 回归先复现“清场却判失败”，修复后等待死亡动画并正确获胜；仍存活且攻击结束时正常判失败。
- 五关所有初始前景块仍完整 16×16，怪物站稳，装饰树不参与碰撞。第二/五关有台阶山坡，第四关有凹地，第三关地下室带开放入口与一名守卫。
- 五关均通过真实鼠标按回放角度发射，在各自库存内获胜，分别使用 **1、3、3、3、4 件物品**。五关回放以 Playwright 时钟推进正常 requestAnimationFrame，物理始终运行生产 Matter；另外新玩家前两关还用正常时钟实测解锁与存档。
- 五关通关记录：`five-browser-victories.json` 和 `campaign-clear-1..5.png`；逐关发射方案：`playability-search.json`。搜索脚本只用于开发验证，不进入游戏自动瞄准逻辑。
- 原版灰色按钮三种状态 PNG 均为 200×20，泥土菜单背景实际加载，无 404；600×690 窄窗口菜单、暂停与物品栏可操作。见 `minecraft-menu.png`、`campaign-pause-small.png`。

## 其他回归

- 新存档仅开放第一关；第一关解锁 TNT，第二关解锁珍珠。锁定关卡不能直接进入，重玩不重复升级，刷新保留进度，损坏存档可恢复默认。
- 独立物品堆叠数量、原版三面方块图标、滚轮/数字键切换和物品栏自动隐藏正常。
- 自由瞄准始终八点；向后和微小力度可发射；右键取消不扣弹；弹药兜垂直于发射方向。
- 原版弩加载采样 WebAudio RMS 非零；释放、取消和暂停均停止加载音，保留原版发射声。
- 圆石落稳后不下沉；像素孔洞同步真实碰撞。建筑失去支撑仍固定，爆炸同时破坏前后景，没有黑洞。
- 怪物行走、停顿、观望、抬手和互相穿行正常；方云随游戏时间移动，暂停冻结物理。
- 五关攻击前后、重开库存和刚体数量通过；正常启动无控制台异常和资源失败；缺引擎或损坏入口均显示错误。
