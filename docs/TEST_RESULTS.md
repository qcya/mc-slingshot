2026-10-17，Windows / Node.js 24 / Edge / Matter.js 0.20.0。完整物理模式，无降级路径。

## 最终执行

`npm run check`：**43/43 核心测试、13/13 Edge 浏览器场景通过**；浏览器部分约 1.3 分钟。此结论来自本地执行，不代表远端 CI 已执行。

## 实际闯关

- 新存档只有第一关可进入，不能通过界面或游戏选关接口跳到锁定关卡。
- 使用真实鼠标拉弓和圆石打过第一关，显示 TNT 奖励并开放第二关。
- 第二关使用独立库存（4 圆石、1 TNT）实际通关，显示珍珠奖励；刷新后第三关仍已解锁、第四关仍锁定。
- 重玩不重复增加解锁等级；破损存档回到第一关。
- 限定库存回放五关均成功，分别使用 **1、3、2、4、5 件物品**。每次发射都检查该种物品剩余数，不能使用尚未解锁或超额物品。
- 回放：`evidence/playability-search.json`。搜索脚本仅供开发，未加入游戏自动瞄准或预设剧情。

## 操作与声音

- 向前平射、向后及高低角度均八点，墙体不会截掉预览；核心验证与同一 Matter 自由飞行位置一致。
- 弹药兜长轴与发射速度垂直。微小力度与反向发射实际生成弹药。
- 原版弩加载采样的 WebAudio 输出 RMS 非零，来源为 `minecraft:crossbow_loading`；释放、右键取消与 ESC 均停止加载音。发射继续使用原版弓声。
- 取消不扣弹；只扣当前物品；重开恢复本关数量；空格子不发射。
- 物品栏方块图标为 64×64 三面纹理组成，显示独立堆叠数；闲置后隐藏，滚轮唤回并循环九格。
- ESC 冻结物理、取消拉弓，恢复后正常运行；无顶部工具栏或共享剩余发数。
- 两颗实际落下的 TNT 中，先爆的一颗将另一颗炸飞，后一颗保留自身引信。

## 物理与画面

- 三种弹药实际发射：圆石稳定、TNT 延迟爆炸、珍珠穿薄墙。
- 玻璃轻碰整片破碎；石材硬于木材；圆石和 TNT 使用方形碰撞；不会睡眠后下沉。
- 五关完整前景方块起步、怪物站稳、重开无刚体泄漏。
- 房屋、家具后墙和阁楼保持固定，爆炸破坏前后景像素；没有黑洞代码或物品。
- 怪物使用完整头身四肢，会行走、停步、观望、抬手并互相穿行。
- 方云随游戏时间移动；远景与远树不参与碰撞。
- 600×690 窄窗口中菜单和物品栏可操作，提示没有共享数量文字。
- 资源无 404、控制台无脚本异常；缺引擎和损坏入口时显示错误。
