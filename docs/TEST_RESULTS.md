# 实际测试结果 — Alpha 0.11.0

2026-10-17，Windows / Node.js 24 / Edge / Matter.js 0.20.0。线上服务使用 Ubuntu / Node.js 22。所有物理验证均为完整 Matter 引擎，无降级模式。

## 最终执行

`npm run check`：**80/80 核心测试、20/20 Edge 浏览器场景通过**；浏览器部分约 3.4 分钟。结论来自本机执行，不代表远端 CI 或真实手机已经测试。

## 十关与战斗

- 十关前景初始方块完整，每块 16×16；地形有阶梯、峡谷、矿道和洞窟。所有怪物出生碰撞空间、脚下支撑经过检查，装饰树不参与碰撞。
- 十关真实鼠标发射并在每项库存内获胜，方案分别用 **1、3、3、3、4、3、4、4、5、7 发**。方案是通关存在性验证，不表示最优解或玩家主观难度。记录见 ten-browser-victories.json、replay-1..10.json、campaign-clear-1..10.png。
- 第十关原方案对巡逻时机敏感，浏览器实测暴露失败后修正：加入宽阔的投弹天井及独立的地下区域。同一七发方案在 15 组初始等待、逐发延迟组合下均获胜，并加入永久回归。
- 烈焰弹使用真实鼠标发射，原版火焰图集实际显示、点燃声能播放、前后木墙像素均减少，没有触发 TNT 爆炸。见 fire-burning.png、fire-browser.json。该次检查物理平均步耗时约 0.64ms、最高 2.4ms，仅是本机数据，不代表安卓性能。
- 燃烧单测覆盖原木、门、书架、工作台、梯子后墙、四邻木块、三格半径、前后景消耗；泥土、熔炉和石材像素及 HP 不变。建筑失去支撑仍固定。
- 监守者独立 128×128 皮肤、较大碰撞与长臂/触角动画；三枚不同圆石或两次爆炸击败。一枚圆石反复接触不重复扣血，第一次爆炸后的落地不会额外致死。珍珠四击、火焰直接伤害零。
- 圆石和 TNT 方形碰撞、落稳不下沉；TNT 四秒引信、即时渐快闪烁、仅接触碎玻璃；爆炸能推动其他弹药；珍珠全程不损伤材料且测量真实墙厚，全部回归通过。
- 四种物品在弹弓上均为 28px，物品栏方块仍使用三面纹理图标。修正 PNG 木叉绑带与弹性带的连接点。

## 操作、菜单和声音

- 安卓模拟环境使用真实 CDP 触摸事件，不是只发鼠标事件。横屏 844×390、竖屏 390×844：拖动、第二指取消、暂停和库存唤回通过；取消不发射、不扣弹，暂停冻结物理。竖屏十关菜单可见并提示横屏。见 android-landscape.png、android-portrait-menu.png。
- 600×690 窄窗口菜单和暂停可操作；MC 按钮、泥土背景、堆叠数量、自动隐藏、滚轮和数字键正常。
- 缺引擎、损坏入口显示明确错误；十关逐一进入、攻击、重开，控制台异常与必需资源失败为零。
- 人物受伤红闪、倒地、白色消散及过关等待通过；人物持续插值、停步观望、抬手、互相穿行通过。
- 弩上弦采样实际 RMS 非零，发射和烈焰点燃播放成功，无播放错误。

## 昵称、排行榜与启动

- 真实 HTTP 测试覆盖身份创建/改名、令牌哈希、重启保留、最佳分排序、并发写入、不计零通关用户、非法输入、请求大小、限流、代理子路径、跨来源写入和私有路径保护。
- 浏览器实际创建昵称、上传成绩、打开榜单、改名、再次查看；网络中断仍可进入游戏，恢复后取得在线身份。
- 审查发现的两个慢网络问题已复现并修复：上传中产生的新成绩继续排队；昵称旧响应不覆盖新请求，也不会把正在游玩的玩家带回菜单。三项专项测试通过并复审。
- Windows 纯 CRLF / LF 启动、清空开发工具 PATH、中文/空格/& 目录及端口冲突回归通过。修复 8.3 路径与完整路径混用导致的 404。
- 实际生成并解压运行 0.11.0 Windows ZIP（35,172,762 字节），核对 114 个文件哈希；隔离开发环境 PATH、占用默认端口后，十关和四种武器均实际测试，控制台异常、失败资源为零。见 windows-player-package.json。ZIP SHA-256：9caf969824c864b4b8565fdab3791577c3203b8d52189203bdafb4e24108205e。

## 边界
